# Expense Tracker

A beginner-friendly command-line expense tracker built with Python and MySQL.

## Features

- Add an expense
- View all expenses
- Update an expense
- Delete an expense
- Validate amount and date input
- Store data in MySQL
- Use environment variables for database credentials

## Technologies

- Python
- MySQL
- mysql-connector-python
- python-dotenv
- Git
- GitHub
